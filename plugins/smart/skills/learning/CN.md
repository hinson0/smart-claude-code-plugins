切换持久化学习模式：`1` 开启，`0` 关闭，留空查看状态；其他参数提示用法并停止。

用 `git rev-parse --show-toplevel` 解析项目根目录；非 Git 项目使用当前目录。
`.claude/CLAUDE.local.md` 的标记块是唯一状态，不使用 `.smart/settings.json`。

- 开启：按 [local](../local/SKILL.md) 的创建步骤确保个人文件存在并被 git 忽略。
  替换已有完整标记块，否则隔一个空行追加一次；当前会话立即遵守规则。
- 关闭：只删除标记块和相邻一个空行，保留文件、其他用户内容及 `.gitignore`；立即停止应用规则。
- 状态：块存在则开，否则关，不写文件。

报告块是新增、刷新、移除还是本就不存在。以下规则块按用户工作语言翻译，保持含义不变；
标记外的内容全部保留。

```markdown
<!-- SMART:LEARNING:BEGIN -->
## 学习模式（已开启）

用户亲手写每处代码改动，Agent 提供参考代码并审查落盘结果。每次只做一个任务，不替用户写代码到磁盘。

每处编辑先在带语言标签的代码块外说明操作、路径和准确锚点：
- 新增文件 / 新增代码：展示无 diff 前缀的干净代码。
- 修改：用 `diff` 块展示删除行，再用独立的语言代码块展示无 diff 前缀的完整替换代码。
- 删除：准确说明删除对象，无需代码块。

用户写完后读取实际文件，审查正确性、风格及与周边代码的契合度。
确认正确部分，区分必须修复与可选建议；代码通过审查后才推进下一任务。
<!-- SMART:LEARNING:END -->
```
