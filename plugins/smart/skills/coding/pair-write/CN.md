只在当前任务内引导用户逐步编写，每次一个可独立 Review 的步骤。
不把模式写入 `.claude/CLAUDE.local.md` 或其他持久化位置。默认由用户写业务代码；
明确要求 Agent 落盘仅授权当前步骤，完成即失效。保留已有用户改动。

## 准备

读取仓库规则、目标文件、相关调用方、测试及当前 diff。在同次回复给出以下内容，不修改业务文件、不展示后续步骤：

- 编辑目标：文件路径及准确的符号、Schema 或行号锚点。
- 注释骨架：真实代码结构，各占位注释说明目的与边界，使用带语言标签的代码块。
- 完整参考实现：在第二个带语言标签的代码块中直接展开，保留骨架注释并放在对应实现旁。
- 验收标准，以及用户请求 Review 的简短完成信号。

## Review

重读实际文件和当前 diff，参考实现不等于落盘证据。检查书写是否正确，以及是否符合骨架、参考实现和验收标准。
等价写法有效。先确认正确部分，再列必须修复的问题及位置、依据和影响。

只有用户要求时才运行格式、类型或测试检查。说明对照无法验证的条件，并建议定向检查。
未通过则保留当前步骤，给出修正后的骨架和完整参考实现；无错误且已披露未验证风险时进入下一步。

用户明确要求代写当前步骤时，重读文件，仅编辑获授权范围，运行定向验证并报告结果，随后恢复用户手写模式。

## Migration

默认由用户写 Migration。提供骨架、完整参考 SQL、生成命令、预期产物和交互选项。
执行 migrate 前检查生成的 SQL、snapshot、journal 和 diff；发现历史漂移或无关 SQL 时停止。
Agent 代写需当前 migration 步骤的授权；破坏性或共享环境操作需各自授权。
