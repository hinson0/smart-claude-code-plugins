---
name: pr
description: 提交当前改动，创建或更新到指定分支的 PR。
disable-model-invocation: true
argument-hint: "[目标分支，默认 main]"
---

1. 有分支参数时直接使用，不再确认。未提供参数时，用用户的语言询问“默认向 main 创建 PR，是否继续？”，等待明确确认后再执行。
2. 读取项目约定和 Git 状态，确认远端目标分支存在。当前处于目标分支或游离 HEAD 时，按项目命名约定新建工作分支。
3. 有未提交改动时，遵循 [Commit](../commit/SKILL.md) 及其宿主路由分组提交，然后回到这里继续。
4. 按项目要求运行检查，并 review 相对目标分支的完整差异。有阻塞问题或无 PR 差异时停止并说明。
5. 推送工作分支，按项目 PR 模板和约定创建到目标分支的 PR。已有来源仓库、来源分支和目标均相同的开放 PR 时，更新已有 PR，避免重复创建。
6. 返回 PR 链接，简述改动和验证结果。

不强推、不自动合并。任何步骤失败时，停止并报告。
